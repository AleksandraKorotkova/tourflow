# TourFlow · запуск на Windows

## 1. Выбери способ установки

**В твою рабочую папку TourFlow.** Распакуй `TourFlow_practice4.zip` и открой извлечённую папку `tourflow_practice4`. Скопируй в свою папку проекта, где уже лежит `main.py`, следующие файлы. Если Windows предложит замену, сначала сравни или сохрани свои свежие версии `main.py` и `collection.py`, если ты меняла их после загрузки ZIP на GitHub.

| Скопируй из распакованного архива | Зачем |
|---|---|
| `gui.py`, `gui_accounts.py`, `gui_tasks.py`, `gui_theme.py` | Приложение, учётные записи, фоновые операции и оформление |
| `main.py`, `collection.py` | Интеграция расчёта и журнала с интерфейсом |
| `requirements.txt`, `.gitignore` | Зависимости и исключение локальных файлов из Git |
| `START_GUI.md` | Эта инструкция |

Для существующего проекта используй свои `config.yaml`, `config.local.yaml`, `.venv` и папку `data`. Если у тебя нет готовой папки `output_from_db`, скопируй её из архива для первого просмотра без пересчёта.

**Отдельная копия.** Распакуй архив и открой в PyCharm извлечённую папку `tourflow_practice4`. Пример исходного Excel, витрина CSV и готовый расчёт уже внутри. Для работы с твоей PostgreSQL перенеси свой `config.local.yaml` в эту папку или создай его на шаге 4.

## 2. Подготовь Python

Открой в PyCharm папку проекта и выбери **View → Tool Windows → Terminal**. В PowerShell текущей папкой должна быть папка с файлами `main.py` и `gui.py`. Это можно проверить командой `Get-ChildItem main.py, gui.py`.

Если `.venv` уже есть, установи зависимости в него:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если папку распаковала как отдельную копию и `.venv` в ней ещё нет, создай окружение на Python 3.11, затем установи зависимости:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Если команда `py -3.11` сообщает, что интерпретатор отсутствует, создай окружение через **Settings → Project → Python Interpreter → Add Interpreter** в PyCharm и выбери установленный Python 3.11. При необходимости отдельно можно проверить Tkinter командой `.\.venv\Scripts\python.exe -m tkinter`. Она открывает тестовое окно.

## 3. Запусти приложение и проверь режим аналитика

```powershell
.\.venv\Scripts\python.exe gui.py
```

1. При первом открытии задай логин администратора, например `admin`, и свой пароль длиной от восьми символов. Это пароль приложения. Для PostgreSQL используется отдельная настройка.
2. Открой вкладку **«Прогноз»**. В выпадающем списке **«График»** доступны девять изображений из приложенного набора. Выбор сразу меняет график внутри окна. После пересчёта список показывает доступные графики нового запуска.
3. Нажми **«Учётные записи»**, введи логин, пароль и выбери **«Аналитик»**. Нажми **«Создать»**.
4. Закрой окно учётных записей и нажми **«Выйти»**. Введи логин и пароль аналитика. Проверь вкладки **«Прогноз»**, **«Качество моделей»** и **«Выводы»**.
5. Нажми **«Пересчитать по готовым данным»**. Для этой команды достаточно `data/monthly_from_db.csv`. При отсутствии этого файла используется `data/monthly.csv`. Дождись статуса **«Расчёт завершён»**. Анализ может занять некоторое время. PostgreSQL и интернет для этого шага не требуются.

Кнопка **«Сохранить PNG»** копирует выбранный график, **«Сохранить CSV»** сохраняет таблицу прогноза, а экспорт метрик доступен на вкладке качества. Кнопка **«Открыть папку результатов»** открывает набор CSV и PNG в Проводнике.

## 4. Подключи PostgreSQL и проверь обновление

1. Нажми **Win + R**, введи `services.msc` и проверь, что служба PostgreSQL запущена. На твоём ноутбуке она называлась `postgresql-x64-18`.
2. Используй уже созданную базу `tourflow`. Для новой установки создай пустую БД с таким именем. Программа создаст рабочие таблицы при первой загрузке.
3. Сверь `host`, `port`, `dbname` и `user` в блоке `storage.postgres` с подключением в DBeaver. Если `config.local.yaml` уже работает, этот шаг завершён. Для отдельной копии создай рядом с `main.py` файл `config.local.yaml` и укажи свой реальный пароль PostgreSQL.

   ```yaml
   storage:
     postgres:
       password: 'твой_пароль_PostgreSQL'
   ```

   Если отличаются другие параметры, их можно переопределить в том же блоке. Сохрани файл в UTF-8 и проверь расширение `.yaml`.
4. Подключись к интернету. Войди в TourFlow под администратором и открой **«Загрузка данных»**. Проверь путь к Excel. Чтобы использовать свежую выгрузку, нажми **«Выбрать Excel…»**. Выбор действует в текущем сеансе. Постоянный путь задаётся в `sources.rosstat.file` в `config.yaml` или `config.local.yaml`.
5. Нажми **«Обновить данные и пересчитать»**. Ход работы виден в этом же окне. После загрузки источников программа соберёт `public.monthly_mart` в PostgreSQL и подготовит CSV. Новый прогноз откроется после завершения анализа. В **«Журнале»** можно выбрать строку и прочитать сообщение от источника. Для просмотра таблиц в DBeaver достаточно открыть соединение после загрузки.

Сообщение **«Новых записей нет»** нормально при повторном запуске. Если Росстат не читается или в выбранной выгрузке нет записей для региона, программа остановит пересчёт и покажет причину. При сбое погоды, курсов или календаря приложение сообщит об этом и попробует собрать витрину из доступных записей PostgreSQL. Если этап расчёта остановится, в приложении останется предыдущий доступный прогноз.

## 5. Как изменить цвет или размер текста

Открой `gui_theme.py` в PyCharm. Измени нужный параметр, сохрани файл и перезапусти приложение.

| Параметр | Что меняет | Текущее значение |
|---|---|---|
| `SECONDARY_TEXT` | Цвет подсказок и подписей | `#334a63` |
| `TEXT` | Основной текст и содержимое таблиц | `#17283b` |
| `ACCENT` | Основные кнопки и активная вкладка | `#185abd` |
| `ACCENT_HOVER` | Основная кнопка при наведении | `#12478f` |
| `BACKGROUND` | Фон окна | `#edf2f8` |
| `SURFACE` | Фон панелей | `#ffffff` |
| `FONT_SIZE` | Размер обычного текста | `11` |

Например, чтобы сделать подсказки ещё темнее, измени строку на `SECONDARY_TEXT = "#23384e"`.

Цвета внутри самих графиков определяются в `visualization.py`. Цвета факта и прогноза задают `BLUE` и `ORANGE`. Чтобы изменения появились на изображениях, выполни пересчёт. Если выберешь другие цвета факта и прогноза, поправь слова в `forecast_legend` в `gui.py`.

## Что хранится локально

Учётные записи хранятся в `.tourflow/accounts.db` в папке проекта. Для паролей в SQLite сохраняются хеши с отдельной солью. Права ролей ограничивают действия в интерфейсе. Доступ к файлам проекта и к PostgreSQL регулируется настройками Windows и самой базы.

Готовые расчёты из приложения хранятся в `.tourflow/runs`. Приложение открывает последний успешно завершённый запуск. Первый вход показывает сохранённый пример из `output_from_db`. Для Git папки с учётными записями и запусками, а также файл `config.local.yaml`, исключены через `.gitignore`.

# TourFlow

Учебная аналитическая система для анализа показателей размещения
туристов в Краснодарском крае.

Проект выполняется по дисциплинам «Проектирование аналитических систем»
и «Прогнозно-аналитические системы».

## Текущее состояние

Реализованы сбор данных, хранение в PostgreSQL, обработка,
анализ, прогнозирование и сохранение графиков.
GUI и BI-дашборд находятся в плане разработки.

## Источники данных

- Росстат: показатели средств размещения из локального Excel.
- Open-Meteo: погода Сочи и Анапы.
- Банк России: курсы USD, EUR и TRY.
- isdayoff.ru: производственный календарь.

## Структура

- main.py — запуск этапов.
- collection.py и ingest/ — сбор и хранение данных.
- processing.py — обработка и месячная витрина.
- analysis.py — сезонность, аномалии, связи факторов и выводы.
- forecasting.py — модели и историческая проверка.
- visualization.py — графики.
- data/ — исходный Excel и месячные CSV.
- output_from_db/ — пример результатов выполненного расчёта.

## Запуск без подключения базы

Требуется Python 3.11.9.
Команды выполняются из папки проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py analyze --csv data/monthly_from_db.csv --out output
```

## Полный запуск с PostgreSQL

1. Создать пустую базу tourflow.
2. Проверить параметры подключения в config.yaml.
3. Создать рядом файл config.local.yaml:

```yaml
storage:
  postgres:
    password: 'пароль_пользователя_PostgreSQL'
```

4. Проверить наличие data/raw/SR_mes_sub.xlsx.
5. Выполнить:

```powershell
.\.venv\Scripts\python.exe main.py all --csv data/monthly_from_db.csv --out output_from_db
```

Таблицы создаются программой автоматически.
DBeaver используется для просмотра базы.

## Ограничения

Основной показатель доступен с января 2022 по июль 2026 года
в приложенном наборе данных. Прогнозные значения не являются фактами.
С 2026 года данные Краснодарского края включают территорию «Сириус».
Росстат загружается из предварительно сохранённого Excel.
